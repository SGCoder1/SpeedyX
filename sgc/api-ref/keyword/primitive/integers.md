# Integral Primitive Types

There are 3 integer types defined in SGCode. All 3 support arithmetic, bitwise, comparison, and equality operators in an intrinsic manner; that is, there is no source code for these types unlike you would see in C#.

Data Type | Size
----------|--------
byte      | 1 byte
char      | 1 byte (ASCII)
int       | 2 bytes (4 bytes if 32-bit)
