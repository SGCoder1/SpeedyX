# Speedy-X Documentation

Welcome to the home documentation page! Here you can view documentaion about the Speedy-X architecure. It features
the SG Code compiler, the SG Assembler, the utilities to create the machine code for said architecure. As a little
inspiration gift, the SG Code compiler supports creating Astro-8 machine code.

Speedy-X is a RISC and CISC hybrid where the assembler text is similar to x86_64, but the binary is fixed.

To get started, see [here]({% link getting-started.md %}).
